# 菲比：缩小 20% 与双虹膜绑定

当前输出：`成片/菲比-双虹膜固定版.mp4`；交付副本：`deliverables/菲比-双虹膜固定版/菲比-双虹膜固定版.mp4`。

角色和虹膜相对首版同时缩为 80%，画面能看到更多脸部和头发：正常形态 `scale` 从 3.9 改为 3.12、虹膜从 250 改为 200；Q 版虹膜底盘从 680 改为 544。第二形态改回 1440×1440 的用户原图，取景倍率按原 1254 画布比例折算为 `2.24 × 1254 / 1440`，约 1.95067。

两枚虹膜放入同一个虹膜组，使用一次共同的运动变换。按对应形态的源眼位设置眼距：

| 形态 | 第一眼源坐标 | 第二眼源坐标 |
| --- | --- | --- |
| 正常 | (511, 550) | (721, 549) |
| Q 版原图 | (877, 735) | (548, 734) |

`准备.py` 读取 `iris_centers_source`，把两枚虹膜排入一张透明组图。组图保留输出尺寸的虹膜细节，以 `iris_layer_registration` 确定角色眼距。两枚虹膜只彼此绑定：主虹膜恢复原来的中央基准，另一枚按固定眼距偏移，均不跟随脸部的横向/纵向运镜。原来的 10 像素全局微移同时作用于整个组。脸部运动时，眼睑从两枚虹膜上方经过。

第一形态合成顺序为背景 → 双虹膜组 → 透明眼眶脸层 → 动态前发 → 固定帽层。帽子使用 `accessories_follow_hair: false`，盖在前发上方。正常形态底图改用 `第一形态-面部-v2.png`，清除额前残留发束；帽层只保留原图中可见帽檐，不补画遮在头后面的整片帽底，以免盖住脸。

**第二形态只有虹膜生成，其他直接采用 `new/1菲比/2.jpg`。** 仅通过 alpha 打开原眼睛内部，帽子、刘海、脸、表情、服装及原有画风均保留原图，不使用此前生成的 Q 版脸层/前发/帽层。合成顺序为背景 → 双虹膜组 → 原图眼眶层；空前发只是兼容旧渲染器的透明占位，不是生成素材，也没有摆动。检查脚本验证原图 RGB 像素完全一致。

后续角色只需适配自身两眼的源坐标及角色取景比例，再重新准备虹膜组即可。同一组的两个虹膜共用大小和运动。调整 `scale`、`iris_size` 或眼距后需要重新运行准备步骤；角色渲染入口已自动执行此步骤。

```powershell
python 角色/菲比/渲染.py
python 角色/菲比/检查.py
```

也可显式准备后使用通用入口：

```powershell
python 角色/菲比/准备.py
python workflow/render.py workflow/菲比-双虹膜固定版.json --validate
python workflow/render.py workflow/菲比-双虹膜固定版.json
```

维持 1080×1576、30 fps、25 帧和参考音轨。`成片/双虹膜固定版检查/` 保存当前全帧检查图、双形态对照及检查结果。回归检查覆盖脸动而虹膜组保持基准、组内固定眼距、眼睑遮挡及旧单虹膜配置行为。

# 菲比分层版

当前采用 **双虹膜固定版**：角色与虹膜相对首版整体缩小 20%，两枚虹膜只彼此绑定，不跟脸运镜。第一形态已清除静止前发残留，固定帽层位于前发上方。第二形态仅使用生成虹膜，其余直接采用 `new/1菲比/2.jpg`，不使用此前生成的 Q 版脸层和前发。当前参数、输出和重建方式见 `双虹膜绑定说明.md`；第一形态修正的实际提示词见 `前发帽层修正提示词.json`。下文只记录历史首版生成过程。

参考采用 `new/1菲比/1.png` 与 `new/1菲比/2.jpg`，副本保存在 `参考/`。使用 **Codex 内置 imagegen**，没有使用 API/CLI 生图。正常形态参考原项目椿头肩图的线条和平涂方式；第二形态保留用户提供的 Q 版比例和粗线。

## 采用的提示词组

以下是本轮生成各图层的提示词规格，具体角色视觉以随附参考图为准。

1. **第一形态完整图**：以菲比第一形态造型图为角色参考、椿完整图仅为手绘平涂画风和正面头肩构图参考。生成金色长卷发、紫眼、白色宽檐帽、蓝金帽带、右侧蓝色十字发夹、蓝白披肩和黑色高领的完整正面头肩像。轻微闭嘴微笑，保留完整帽檐和长发，透明背景，不画法杖和手、不画脸颊羞涩线，不添加文字。
2. **第一形态脸层**：以完整图为编辑目标，保持画布、比例、位置、帽子、后发、黑色侧发带、服装、眉毛、嘴及眼睑；只移除前额刘海、脸前发束及发夹，补全额头。两只眼睛内部的眼白、虹膜和高光全部真正透明，保留上下眼睑、睫毛和眼角。外围背景同样透明。
3. **第一形态前发**：同一完整图仅保留前额刘海、脸前短发束和蓝色发夹，保留原构图坐标。去掉帽子、后发、黑色发带、眼睛眉毛、皮肤及服装。完整原画布，其余真正透明，不单独居中或裁切发片。
4. **第一形态虹膜**：参考完整图的眼睛，生成独立完整圆形紫色虹膜；上部深紫、下部淡紫，中央细长深色菱形瞳孔，不改成四角星。无眼睑、睫毛、眼白、皮肤、文字，无白色高光和反光；方形透明画布中央一枚完整圆盘。
5. **第二形态脸层**：以 Q 版原图为编辑目标，保持方形画布、角色比例、粗棕色轮廓、白帽紫蓝帽带、后方金色长发、笑嘴及蓝白衣服。只移除前额刘海及蓝色发夹、补全底层额头，去掉脸颊红晕；两只圆眼保留深棕外圈，内部紫色和白色高光全部生成真实透明，不改成正常动漫比例。
6. **第二形态前发**：同一 Q 版原图仅保留完整前刘海和面颊前发束及蓝色十字发夹，保持粗棕轮廓、金色内线和淡金填色，保留全画布位置；其余透明，不含帽子、皮肤、眉眼、后发和服装。该图层在最终配置中固定，**不甩动**。
7. **第二形态虹膜**：参照 Q 版圆眼，生成完整圆形紫色虹膜，深棕外圈、上半深紫、下半淡紫及弧形分界。去掉两处白色高光，不添加星形或写实纤维；一枚完整圆盘，外围真正透明。

生成原件及各独立图层位于 `素材/分层-v1/`。正常形态脸层和前发均为 1236×1272；Q 版脸层与前发均为 1254×1254。完整基准图只用于生成参考；实际配准以最终相同尺寸的脸层和前发为准。

## 接入原工作流

- `准备.py` 使用原项目的预乘 alpha 采样和图层合成函数，整理虹膜画布，并把未选中眼睛的虹膜合成在其眼睑之下，选中眼眶继续透明。原始生成图保留。
- 正常形态选左侧眼心 `(511,550)`，取景倍率 3.9；保留原 13 帧运动和前发惯性，后发及帽子固定。
- Q 版选右侧眼心 `(763,630)`，取景倍率 2.8；保留原 12 帧反向镜头运动，前发惯性全为零。脸及头发照常随镜头整体平移。
- 正常形态主虹膜为 250 像素。Q 版的圆眼没有正常形态的白色眼白，采用 680 像素虹膜底盘覆盖圆眼及平移余量；大部分底盘被脸层遮住，实际可见范围由圆眼轮廓决定，避免运动时露出白缝。
- 采用单位 `hair_registration`，启用合并变换及预乘 alpha 的采样路径。无需修改共享渲染器。
- 1080×1576、30 fps、13＋12＝25 帧，硬切；音轨使用参考视频从 1.1 秒起的片段。额外镜头轻移沿用 10 像素设置。

## 重建与检查

在仓库根目录：

```powershell
python 角色/菲比/准备.py
python 角色/菲比/渲染.py --validate
python 角色/菲比/渲染.py
python 角色/菲比/检查.py
```

角色输出为 `成片/菲比-分层版.mp4`，工作流目录也有 `workflow/菲比-分层版.json`，可用通用渲染入口生成 deliverables 中的副本。

检查脚本核对 1080×1576、30 fps、25 帧、AAC 音轨、完整解码和 Q 版摆动数组全零，并导出全 25 帧接触表和双形态对照。已查看全部帧，收紧正常形态取景以避免另一只眼在末尾从画边露出。素材中仍保留 AI 生成的细微造型差异，不能保证与参考逐像素一致。

旧的 `workflow/菲比-双形态样片.json` 及其整图平移样片保留。

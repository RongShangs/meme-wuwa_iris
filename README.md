# meme-wuwa_iris

一套《鸣潮》角色虹膜转场短片的素材与可复刻合成工程。仓库包含角色透明分层、参考图片和视频、历史版本、研究记录、配置、脚本与已导出的样片。

当前成片按 **心 → 达尼亚 → 西格利卡 → 爱弥斯 → 弗洛洛 → 卡提 → 椿 → 漂泊者** 排列。每位角色包含两个镜头；保留声痕开头、前发惯性、轻微镜头平移及瞳孔放大结尾。

## 快速开始

需要 Python 3.10+、`ffmpeg` 和 `ffprobe`。在仓库根目录运行：

```bash
python -m pip install -r workflow/requirements.txt
python workflow/render.py workflow/1080p-心前发画风修正.json --validate
python workflow/render.py workflow/1080p-心前发画风修正.json --output output.mp4
```

默认配置为 1080 × 1576、30 fps，保留参考视频的竖屏比例。`--output` 可以避免覆盖仓库里已有样片。各角色的 `项目.json` 和 `渲染.py` 放在对应目录中，例如：

```bash
python 角色/漂泊者/渲染.py
```

素材和音频路径相对于配置文件解析；参考视频位于 `素材/参考原始文件/原参考视频.mp4`。想自行重排时，复制完整配置并调整 `shots` 中角色镜头的顺序，再用连续音轨渲染。生成后仍需逐帧检查眼眶边缘、前发遮挡、运动和音画同步。

## 目录

- `角色/`：各角色的透明素材、参考图、独立配置和片段。
- `workflow/`：分层合成器、开头/结尾动画、依赖和各版本配置。
- `素材/`：开头声痕以及项目使用的原始参考文件。
- `assets/`、`research/`、`tools/`：历史素材、研究记录和早期脚本。
- `deliverables/`：各轮样片及最终视频；其中包含历史版本，不代表都是最终选择。

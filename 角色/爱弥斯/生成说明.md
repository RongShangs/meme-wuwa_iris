# 爱弥斯素材生成说明

使用 Codex 内置 imagegen。第一形态：参考角色图与项目手绘风格，生成透明正面原画；分生成面部透明眼眶层、含光环与配饰的前发层，并依据眼睛特写生成紫褐到金色、中央四角星的完整虹膜。第二形态：参考机甲图生成单张透明正面头盔图，保留白银头盔、金色角、青色面罩，不生成眼睛。

尝试将第一形态素材生成到肩部，但模型改变了长发及衣领，未采用。当前成片仍使用完整上半身图层；后续生成应保留角色长发、衣领和完整头饰，在构图上只画到肩膀，并为运镜留余量。

## 前发修正

使用 Codex 内置 imagegen 参考原人物图重新生成前发与面部底图：前发保留前额和面颊前方的发片，去掉肩后的长发；底图保留后发、光环和羽翼配饰，并保留透明眼眶。入场开始的位置向左调整，随后平滑回到原运镜。

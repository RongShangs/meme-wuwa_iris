# 鸣潮「瞳孔」短片：可复刻制作流程

这套流程从一组**透明 PNG 素材**合成短片。当前示例使用达妮娅两种形态，沿用 V19 的镜头尺寸、25 帧运动、刘海甩动和音轨位置；后来根据要求改为头饰跟随刘海运动，因此与 V19 不再逐像素相同。

这是一套可重建合成的流程，不是按一次命令就能自动生成合格角色原画的工具。AI 生图可能改变发型、表情、透明边缘或配饰位置，需要检查和迭代；即使用相同提示词也不保证重新生成完全一致的图片。要精确重建 V19，请保留已采用的 PNG、配置、脚本、音轨输入与依赖。

## 一、最终画面和参考节奏

- 输出示例：竖屏 540×788、30 fps。保持原视频的 135:197 画幅比例，最终高分辨率输出可用 1080×1576。
- 每位角色按**第一形态一侧脸 → 第二形态另一侧脸**排列；再继续下一位角色。每张脸的虹膜固定在画面中央，脸部和透明眼眶随镜头横向运动，眼睑始终在虹膜上方。
- V19 没有额外高光；虹膜必须是完整、独立的圆形透明图层，不能从半遮挡眼睛直接截取。不要画脸颊害羞红线。同一角色的两种形态不必共用虹膜，应按各自参考分别制作。
- 每个角色第二形态默认比第一形态更凶或更冷，优先通过嘴形和嘴角表达；眉毛只作轻微调整，避免用大幅度皱眉替代表情设计。
- 参考原片第 33–57 帧：第一段 13 帧、第二段 12 帧，直接切镜，不叠化。入口快速减速，中段保持缓慢滑动，末尾再加速；第二段水平运动方向反转。测量方法和误差见 [原片运动测量](../research/原片运动测量.md)。测得的是图像匹配近似，不是原片工程关键帧。
- 音轨示例从原视频 1.1 秒开始，共 25 帧。以后多人版本应按目标音频逐段核对切点，不要只复制总时长。

## 二、素材清单

每个镜头需要以下四张透明 PNG：

| 配置项 | 内容 | 要求 |
| --- | --- | --- |
| `face` | 脸、后发、身体与服装 | 无前额刘海、无头部配饰；眼眶内部整块透明，保留上下眼睑和眼角；没有脸颊红线 |
| `hair` | 前额刘海 | 完整的透明发片，保留原画布位置及所有发梢，不要预先裁掉顶部 |
| `accessories` | 发箍、蝴蝶结、白色饰物、蓝金发饰等 | 完整生成的透明配饰，位置与角色基准图一致；不要从合成截图挖一块贴上 |
| `iris` | 虹膜 | 单独生成完整圆形透明图；保留角色瞳孔造型，不包含眼白、眼睑或固定高光 |

`face`、`hair` 和 `accessories` 在**同一个镜头内必须具有完全相同的像素尺寸和构图坐标**，例如示例为 1199×1312。它们可以跨形态共用，但只有在发型、位置和造型确实一致时才共用；不同角色可以用不同尺寸的原画布。`iris` 可使用独立尺寸；示例为 156×156。

素材依次合成：**背景 → 固定虹膜 → 完整脸部/眼眶 → 动态刘海 → 配饰**。默认头饰和刘海共用相同旋转中心及运动变换；不随刘海运动的绷带等可设置 `"accessories_follow_hair": false`，没有配饰则将 `accessories` 设为 `null`。实现时先在完整源画布叠加脸、动态刘海、配饰，再用镜头取景；虹膜保持画面中心并放在这些图层下方。不要通过在脸上临时挖屏幕圆洞来强制显示虹膜，否则运动时会盖在脸上。

## 三、生成和检查素材

1. **收集角色基准**：优先用可靠的角色原画、游戏截图或用户确认的设定；区分官方造型和二创设计。记录发型、发饰、瞳孔、两种形态及左右脸。V19 基于已有二创参考，不能声称是官方逐项校对版。
2. **生成完整脸基准图**：先确保两种形态的脸、发型、配饰、头部角度和画风一致。参考原片使用简洁手绘线条、平涂和克制的明暗；第二形态可以更凶，但要保证眼部尺度和位置适合后续配准。
3. **生成透明脸层**：以基准图为输入，让模型移除前额刘海与头饰、移除羞涩红线，并把两只眼睛的眼白和虹膜**直接生成真正透明**，保留完整眼睑、睫毛、眼角、后发、服装与原画布。不要把白色或黑色填充当成透明。
4. **生成透明发片和配饰**：分别以完整脸为参照，生成原尺寸、原位置的完整前刘海和完整配饰透明层；包括发箍及侧面发饰。禁止在素材阶段截掉发片上缘或配饰一角；构图由最后的镜头完成。
5. **生成透明虹膜**：以真实角色眼睛的局部为参考，保留可见的形状、配色和图案，只推断被遮挡部分。不要把模糊细节擅自替换成标准星形；不要画高光。先用高分辨率生成，然后等比例缩放为需要的显示尺寸。
6. **先审查再动画**：将脸部透明眼眶放在鲜绿色或棋盘格背景上放大检查；上下睫毛、眼角、眼白及旧虹膜边缘须逐点确认。再将虹膜叠在下层，检查眼睑遮挡。把刘海和配饰以零偏移叠到脸上，检查发饰是否完整、脸颊是否有红线、头发是否穿模。移动刘海至甩动极限，检查额头补全、边缘缝隙、重复发丝和配饰遮挡。

可用提示词框架（图片中的具体设定由参考图决定）：

```text
脸层：以角色完整基准图为准，保持画幅、位置、发型和表情。
移除前额刘海与头部配饰，补全遮挡的额头；去掉脸颊红晕线。
两只眼睛内部的虹膜和眼白全部为真实透明，保留上下眼睑和眼角。
外部背景透明；保留完整画布，不裁切。

刘海层：以同一基准图为准，只生成完整前额刘海与前侧发束。
保留原始画布、位置、比例和边缘；其他区域透明，不包括脸和配饰。

配饰层：以同一基准图为准，只生成完整头饰，保留原画布、位置、
尺寸和各部件尖端；其他区域透明，不包含脸或头发。

虹膜层：以角色眼睛近景为视觉基准，单独生成完整圆形虹膜，
复现可见的颜色和图案，补全被眼睑遮挡的部分；背景透明，无高光。
```

生成后检查真实 alpha，而不是仅看黑色/白色预览。示例脚本只验证指定瞳孔中心为透明，**不能自动证明整个眼眶、眼角和发片边缘都干净**；需要放大和逐帧人工检查。

## 四、运行示例

需要 Python 3、`numpy`、`opencv-python`，以及 PATH 中的 `ffmpeg` 和 `ffprobe`。

```powershell
# 在仓库根目录运行
python -m pip install -r workflow/requirements.txt
python workflow/render.py workflow/denia.example.json --validate
python workflow/render.py workflow/denia.example.json
```

输出为 `deliverables/reusable/denia-config.mp4`。配置文件内的相对路径以**配置文件所在目录**为基准；示例音频使用仓库中的参考视频相对路径。`--output '其他路径.mp4'` 可覆盖输出位置。如果不使用音频，将配置中的 `"audio"` 设为 `null`；结果为无声视频。

新增角色时，复制 `denia.example.json`，逐段替换 `shots` 中的素材路径、瞳孔坐标及运动数据；按顺序追加两个形态，再追加其他角色。每段可以共用或分别使用刘海、配饰和虹膜。不同角色的瞳孔造型应按角色单独生成，大小按最终画面校准。

## 五、配置参数

- `canvas.width/height/fps`：成片尺寸和帧率。宽高必须为偶数。
- `eye_center_source`：透明脸图上选定眼睛的中心坐标，单位为源图像像素。该点在脸层必须透明；脚本将它定位到画面中心作为镜头基准。
- `scale`：完整脸画布放大到输出画面的倍率；示例 `1.3`。这控制脸的镜头大小；虹膜显示大小由输入 PNG 像素尺寸决定，**两者需一起核对**。
- `iris_size`：可选的最终虹膜宽高，单位为输出画面像素。先统一该值，再调整各角色脸部 `scale` 以适配同一虹膜；`two-characters-v2.json` 将上一版 156 像素缩为 133 像素（约 15%）。
- `camera_dx`：该镜头逐帧横向位移，单位为输出画面像素；正数向右。纵向位移固定为 0。数组长度即该镜头的帧数。
- `hair_sway`：逐帧刘海相对位移，单位为输出画面像素；与 `camera_dx` 数组长度必须相同。根据入场方向反转并检查惯性，避免头发贴着脸同步死板移动。
- `hair_pivot`：刘海旋转枢轴在原始完整画布中的像素坐标；`rotation_degrees_per_sway` 控制旋转角度与摆动量的比例。需要更多精细形变时应制作差分或骨骼动画，当前实现为整张发片的平移和旋转近似。
- `hair_registration`：可选的 6 个仿射矩阵数值，用于把未预缩放的原始透明发片对齐到脸部画布。启用后，脚本把配准、摆动与镜头变换合成一次采样，并对透明边缘使用预乘 alpha；可以减少反复缩放导致的模糊与暗边，但无法恢复源图缺失的细节。
- `audio.path/start_seconds`：音频文件路径及截取起始秒数；可以是含音轨的视频。将整个 `audio` 设为 `null` 可无声导出。要检查输入确实包含音轨，脚本允许没有音轨的文件并会生成无声片。

示例数据是 540×788 输出坐标。要输出 1080×1576，应将 `width`、`height`、`camera_dx`、`hair_sway`、`scale` 和虹膜 PNG 的显示宽高同步乘 2；源图 `eye_center_source` 与 `hair_pivot` 不变。源图本身分辨率不足时，放大不会增加真实细节。

## 六、交付前检查

- 逐帧检查虹膜始终处于眼眶内部；整个脸移动时，眼睑应遮住虹膜，不能出现漂浮在脸前或切换瞬间消失。
- 检查两形态的眼中心、视觉尺寸和左右方向；修复眼角残留、白边、配饰断裂、额头接缝、刘海重复线和露底。
- 对照原片关键帧和音频核对切点；必要时修改逐帧数组，不靠主观拖动估算。
- 用 `ffprobe` 检查帧率、帧数、尺寸和音轨；用 `ffmpeg -v error -i 文件.mp4 -f null -` 检查完整解码。按播放器循环检查切换，尤其是第一帧和最后一帧。
- 保留采用的透明 PNG 原件、配置、渲染脚本、音轨来源和最终输出；不要只保留 MP4。发布前核实角色、参考素材和音乐的使用范围。
